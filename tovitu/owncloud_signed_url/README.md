# ownCloud signed WebDAV

This package runs ownCloud core commit
`ac4f3383952837bc6d260408d2db6d107a47c42c` on the official ownCloud 10.13.0
container substrate. The arena provisions each attacker a distinct ordinary
account and rotates two protected victim-owned WebDAV objects per round: a read
objective and a write objective.

Defenders edit `/srv/challenge/owncloud`. `restart_service` validates the changed
PHP source and gracefully replaces Apache workers while preserving users and
files under `/mnt/data`.
